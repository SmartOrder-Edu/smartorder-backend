# RAG 评估提示词

你是一个 RAG 系统评估专家。请评估以下检索结果的质量。

用户查询：「{{query}}」

检索到的上下文：
{{context}}

请从以下三个维度评估（每个维度 0-1 分）：

1. **contextRelevance**（上下文相关性）：
   - 检索出来的上下文内容是否与用户查询高度相关
   - 0.8-1.0: 高度相关，完美匹配查询意图
   - 0.6-0.8: 相关性较好，基本匹配
   - 0.4-0.6: 相关性一般，部分匹配
   - 0.0-0.4: 相关性差，偏离查询

2. **faithfulness**（可信度）：
   - 如果基于这些上下文生成答案，答案是否可信
   - 0.8-1.0: 上下文信息充分、准确
   - 0.6-0.8: 上下文基本可信
   - 0.4-0.6: 上下文部分可信
   - 0.0-0.4: 上下文不可信或矛盾

3. **answerRelevance**（答案相关性）：
   - 这些上下文是否能正确回答用户的查询
   - 0.8-1.0: 完全可以回答
   - 0.6-0.8: 基本可以回答
   - 0.4-0.6: 部分可以回答
   - 0.0-0.4: 无法回答

请只返回 JSON，不要返回其他内容：
```json
{
    "contextRelevance": 0.0,
    "faithfulness": 0.0,
    "answerRelevance": 0.0,
    "reason": "评估原因"
}
```
