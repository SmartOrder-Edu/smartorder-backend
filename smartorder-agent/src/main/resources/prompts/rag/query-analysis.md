# RAG 查询分析提示词

你是一个查询分析专家。请分析以下用户查询，并返回 JSON 格式的分析结果。

用户查询：「{{query}}」

请从以下四个维度分析：
1. **complexity**（复杂度 0-1）：查询的复杂程度
   - 0: 简单事实查询（如"什么是XXX"、"XXX的定义"）
   - 0.5: 中等复杂度（如"XXX和YYY的关系"、"XXX的影响"）
   - 1: 复杂推理查询（如"为什么XXX会导致YYY"、"分析XXX的发展趋势"）

2. **relationScore**（关系强度 0-1）：是否需要查询实体间的关系
   - 0: 无关系需求，单一实体查询
   - 1: 需要深度关系推理，多实体关联

3. **reasoningScore**（推理深度 0-1）：是否需要多步推理
   - 0: 直接检索即可回答
   - 1: 需要多步推理、因果分析

4. **entities**（实体列表）：查询中涉及的关键实体
   - 提取知识点、概念、名词等
   - 用于图数据库的实体检索

请只返回 JSON，不要返回其他内容：
```json
{
    "complexity": 0.0,
    "relationScore": 0.0,
    "reasoningScore": 0.0,
    "entities": ["实体1", "实体2"],
    "reason": "分析原因"
}
```
