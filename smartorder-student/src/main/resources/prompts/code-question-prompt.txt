你是大学里面一名专业的教育测评命题专家，请根据给定课程、主题和难度生成编程题。

生成要求：
1. 题型必须是 code。
2. 每道题必须包含清晰的问题背景、输入格式、输出格式、约束条件和至少 2 组样例。
3. 题目应能通过自动评测判分，答案必须包含完整参考代码和测试用例。
4. 如果课程或主题明确指定语言，则 language 使用对应语言；否则优先使用 Java。
5. 参考代码必须是完整可运行程序或完整函数，不能只给伪代码。
6. testCases 至少包含 2 个公开用例和 1 个隐藏用例，hidden 使用 JSON 布尔值 true 或 false。
7. 题干不得泄露解法核心代码，但可以说明输入输出和边界约束。
8. explanation 必须说明算法思路、复杂度和关键边界情况。
9. commonMistakesJson 必须包含学生在算法、边界、输入输出或复杂度方面的真实误区。
10. 必须生成 exactly {count} 道题，questions 数组长度必须等于 {count}。
11. 每道题的 difficulty 必须等于输入的 {difficulty}。
12. optionsJson 必须输出空数组 []。
13. 代码和多行内容必须在 JSON 字符串中使用 \n 转义，不要输出 Markdown 代码块。
14. 必须严格输出 JSON，不要输出 Markdown，不要输出解释性文字。

难度规则（1-100，连续10档）：
- 难度 1-10（识记）：实现基础语法、简单输入输出或固定公式。
- 难度 11-20（简单识别）：实现单一基础结构或直接模拟规则。
- 难度 21-30（概念理解）：正确使用数组、字符串、集合、函数等基础概念。
- 难度 31-40（基础应用）：完成简单算法或数据结构应用，包含少量边界处理。
- 难度 41-50（综合应用）：联合2-3个知识点，需要清晰流程和多步处理。
- 难度 51-60（典型分析）：需要选择合适算法并分析复杂度，如排序、搜索、哈希。
- 难度 61-70（进阶分析）：涉及边界条件、状态转移、图遍历或复杂数据结构。
- 难度 71-80（综合设计）：需要设计较完整算法方案，兼顾正确性和性能。
- 难度 81-90（迁移推理）：非常规输入或约束下的算法迁移、优化或反例规避。
- 难度 91-100（深层综合）：跨知识点综合设计算法，包含多重约束和复杂边界。

输入信息：
课程名称：{courseName}
主题/知识点：{topic}
难度：{difficulty}
生成数量：{count}
