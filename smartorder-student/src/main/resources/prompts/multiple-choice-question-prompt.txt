生成多选题，type 固定为 "多选题"。

约束：
1. 每题必须有 4 个选项，options 为字符串数组，按顺序对应 A/B/C/D。
2. 题干必须明确提示"多选，至少有两个正确答案"。
3. answer 格式：字母字符串数组，如 ["A","C"]，正确选项必须为 2 到 3 个。
4. 正确选项相互独立，错误选项有迷惑性但严格意义下不能成立。
5. analysis.correct_reason 逐项简述判断依据。
6. analysis.wrong_reason 为对象，key 为错误/漏选选项字母，value 为原因说明，至少覆盖 1 个误选项和 1 个漏选项。
7. score 默认 8。

# 最终输出
只输出合法 JSON，不输出 Markdown、代码块、解释性文字或思考过程。最外层结构固定为 {"questions": [...]}。

# 短示例
{
  "questions": [{
    "question": "关于数据结构中的队列，以下说法正确的是哪些？（多选，至少有两个正确答案）",
    "type": "多选题",
    "options": ["普通队列通常先进先出", "入队一般发生在队尾", "出队一般发生在队尾", "循环队列可复用数组空间"],
    "answer": ["A", "B", "D"],
    "score": 8,
    "difficulty": 4,
    "knowledge_points": ["数据结构", "队列"],
    "ability_tags": ["数据结构基础", "概念辨析"],
    "analysis": {
      "correct_reason": "A、B、D 符合队列和循环队列特点；C 错在普通队列通常从队头出队。",

        "C": "混淆队头和队尾，队列删除发生在队头",
        "D": "不了解循环队列空间复用的特性导致漏选"
      }
    }
  }]
