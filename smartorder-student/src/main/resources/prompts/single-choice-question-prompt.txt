生成单选题，type 固定为 "单选题"。

约束：
1. 每题必须有 {{optionCount}} 个选项，options 为字符串数组，按顺序对应 A/B/C/D...
2. answer 格式：单一字母字符串，如 "A"、"B"、"C"、"D"，且只能有 1 个正确选项。
3. 不要出现"以上都对""以上都不对""无法判断"等选项。
4. 干扰项要合理、有迷惑性，但严格意义下不能成立。
5. analysis.correct_reason 简短说明正确项依据。
6. analysis.wrong_reason 为对象，key 为错误选项字母，value 为该选项的错误原因，至少覆盖 2 个错误选项。
7. score 默认 5。

# 最终输出
只输出合法 JSON，不输出 Markdown、代码块、解释性文字或思考过程。最外层结构固定为 {"questions": [...]}。

# 短示例
{
  "questions": [{
    "question": "数据结构中，栈的访问特点是什么？",

    "options": ["先进先出", "后进先出", "随机访问", "按优先级访问"],
    "answer": "B",

    "knowledge_points": ["数据结构", "栈"],
    "ability_tags": ["数据结构基础", "概念理解"],

        "D": "把栈和优先队列混淆"
      }
    }
  }]
}
