生成简答题，题型代码固定为 short_answer。

约束：
1. optionsJson 必须是空数组 []。
2. 题干聚焦一个核心问题，可要求解释原因、比较差异、说明步骤或分析机制。
3. answerJson 格式：{"referenceAnswer":"精炼参考答案","scoringPoints":[{"point":"评分点","scoreRatio":0.5}],"keywords":["关键词"]}。
4. scoringPoints 中每个评分点必须可独立判分，scoreRatio 总和必须等于 1.0。
5. referenceAnswer 完整但精炼，能作为教师判分依据。
6. 多行内容必须在 JSON 字符串中使用 \n 转义。

# 最终输出
只输出合法 JSON，不输出 Markdown、代码块、解释性文字或思考过程。最外层结构固定为 {"questions": [...]}。

  }]
}
