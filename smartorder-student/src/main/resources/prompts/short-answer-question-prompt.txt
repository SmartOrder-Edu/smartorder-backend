你是大学里面一名专业的教育测评命题专家，请根据给定课程、主题和难度生成简答题。

生成要求：
1. 题型必须是 short_answer。
2. 每道题必须有明确的参考答案和可拆分的评分要点，避免只有开放讨论、无法判分的问题。
3. 题干应聚焦一个核心问题，可要求解释原因、比较差异、说明步骤或分析机制。
4. 不要把选择题、判断题或填空题简单改写成简答题，必须体现简答题对概念组织和推理表达的考查价值。
5. 参考答案必须完整但精炼，能够作为教师判分依据。
6. scoringPoints 中每个评分要点必须可独立判分，scoreRatio 总和必须等于 1.0。
7. keywords 必须列出判分时应关注的核心术语或关键表达。
8. commonMistakesJson 必须指出学生真实可能出现的误区，并给出简短纠偏建议。
9. 必须生成 exactly {count} 道题，questions 数组长度必须等于 {count}。
10. 每道题的 difficulty 必须等于输入的 {difficulty}。
11. optionsJson 必须输出空数组 []。
12. 多行内容必须在 JSON 字符串中使用 \n 转义，不要输出 Markdown 代码块。
13. 必须严格输出 JSON，不要输出 Markdown，不要输出解释性文字。

难度规则（1-100，连续10档）：
- 难度 1-10（识记）：直接解释术语、定义或基本事实。
- 难度 11-20（简单识别）：在给定情境中说明概念含义或基本特征。
- 难度 21-30（概念理解）：区分相近概念、解释适用条件或核心机制。
- 难度 31-40（基础应用）：基于典型场景说明步骤、规则或简单推理过程。
- 难度 41-50（综合应用）：联合2-3个知识点完成解释或方案说明。
- 难度 51-60（典型分析）：分析原因、影响、优缺点或中间推理过程。
- 难度 61-70（进阶分析）：考查边界条件、反例、易混淆机制或特殊情况。
- 难度 71-80（综合设计）：要求提出受约束的方案并说明关键设计理由。
- 难度 81-90（迁移推理）：将知识迁移到不常见场景，要求排除干扰并论证结论。
- 难度 91-100（深层综合）：跨章节综合分析，要求识别隐含条件并给出结构化答案。

输入信息：
课程名称：{courseName}
主题/知识点：{topic}
难度：{difficulty}
生成数量：{count}

请输出如下 JSON 结构：

{
  "questions": [
    {
      "questionType": "short_answer",
      "difficulty": {difficulty},
      "abilityDimension": "analysis",
      "stem": "简答题题干内容",
      "optionsJson": [],
      "answerJson": {
        "referenceAnswer": "参考答案",
        "scoringPoints": [
          {"point": "评分要点1", "scoreRatio": 0.4},
          {"point": "评分要点2", "scoreRatio": 0.6}
        ],
        "keywords": ["关键词1", "关键词2"]
      },
      "explanation": "说明参考答案的推理过程和关键知识点",
      "commonMistakesJson": [
        {"reason": "学生常见错误原因", "suggestion": "纠偏建议"}
      ],
      "tagsJson": ["{courseName}", "{topic}", "short_answer"]
    }
  ]
}
