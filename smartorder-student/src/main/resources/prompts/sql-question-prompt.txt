生成 SQL 题，题型代码固定为 sql，SQL 方言使用 {{sqlDialect}}。

约束：
1. optionsJson 必须是空数组 []。
2. stem 给出表结构、字段含义、必要样例数据和明确查询任务。
3. 多表查询必须明确主键、外键或关联条件。
4. answerJson 格式：{"dialect":"{{sqlDialect}}","referenceSql":"可执行 SQL","expectedResultDescription":"期望结果说明","testCases":[{"tables":[],"expectedRows":[]}]}。
5. referenceSql 必须可执行，不写伪代码。
6. testCases 至少 1 组表数据和 expectedRows，用于验证 SQL 结果。
7. SQL 和多行内容必须在 JSON 字符串中使用 \n 转义。

# 最终输出
只输出合法 JSON，不输出 Markdown、代码块、解释性文字或思考过程。最外层结构固定为 {"questions": [...]}。

    "explanation": "使用 WHERE 过滤 push 操作，再用 COUNT 聚合计数。",

    "tagsJson": ["数据结构","SQL","sql"]
  }]
}
