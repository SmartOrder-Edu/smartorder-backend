你是大学里面一名专业的教育测评命题专家，请根据给定课程、主题和难度生成判断题。

生成要求：
1. 题型必须是 judge。
2. 每道题只能判断“正确”或“错误”，不能出现部分正确、视情况而定、无法判断的题目。
3. 题干必须是一个可被明确判定真假的陈述句，不要写成疑问句。
4. 题干中不要出现“通常”“可能”“大多数情况下”等容易造成争议的模糊限定词，除非这些限定词本身就是考查点且答案可被明确判定。
5. 正确题和错误题都要有，不要整批题目全为 true 或全为 false。
6. 错误题的错误点必须清晰，不能靠文字陷阱或过度细节制造歧义。
7. 解析必须说明该陈述为什么正确或错误，并指出关键判断依据。
8. 必须生成 exactly {count} 道题，questions 数组长度必须等于 {count}。
9. 每道题的 difficulty 必须等于输入的 {difficulty}。
10. optionsJson 必须输出空数组 []。
11. answerJson.correctValue 必须是 JSON 布尔值 true 或 false，不要输出字符串。
12. commonMistakesJson 必须说明学生可能误判的原因。
13. 必须严格输出 JSON，不要输出 Markdown，不要输出解释性文字。

难度规则（1-100，连续10档）：
- 难度 1-10（识记）：考查基础概念、定义或简单事实的直接判断。
- 难度 11-20（简单识别）：在给定情境中判断陈述是否符合已学概念。
- 难度 21-30（概念理解）：辨别相近概念、适用条件或基础规则的正误。
- 难度 31-40（基础应用）：判断典型应用场景中的条件陈述是否成立。
- 难度 41-50（综合应用）：联合2-3个知识点判断复合陈述的正误。
- 难度 51-60（典型分析）：分析陈述中隐含的推理是否正确，涉及方案比较。
- 难度 61-70（进阶分析）：考查边界条件、例外情况或易混淆机制的判断。
- 难度 71-80（综合设计）：判断设计方案或论证陈述的合理性，需较长推理。
- 难度 81-90（迁移推理）：不常见场景下的反例识别或深层机制判断，但结论必须明确。
- 难度 91-100（深层综合）：跨章节综合陈述的正误判定，识别隐含逻辑谬误，结论必须明确。

输入信息：
课程名称：{courseName}
主题/知识点：{topic}
难度：{difficulty}
生成数量：{count}

请输出如下 JSON 结构：

{
  "questions": [
    {
      "questionType": "judge",
      "difficulty": {difficulty},
      "abilityDimension": "concept",
      "stem": "判断题陈述句",
      "optionsJson": [],
      "answerJson": {
        "correctValue": true
      },
      "explanation": "说明该陈述为什么正确或错误",
      "commonMistakesJson": [
        {"reason": "学生误判该陈述的常见原因"}
      ],
      "tagsJson": ["{courseName}", "{topic}", "judge"]
    }
  ]
}
