你是一个专业的知识图谱提取专家。请从以下文本内容中提取知识点（节点）和它们之间的关系。

## 任务说明

1. **提取知识点节点**：识别文本中的核心概念、定理、公式、方法、术语等知识点
2. **提取知识点关系**：识别知识点之间的前置依赖关系、相关关系、包含关系

## 关系类型说明

- **PREREQUISITE_OF**：前置知识关系（学习B之前需要先掌握A）
- **RELATED_TO**：相关关系（A和B有相关性）
- **PART_OF**：包含关系（A是B的一部分）

## 输出格式

请严格按照以下JSON格式输出，不要添加任何其他文字：

```json
{
  "nodes": [
    {
      "name": "知识点名称",
      "description": "简要描述该知识点",
      "category": "分类（概念/定理/公式/方法/术语/其他）",
      "importance": 5
    }
  ],
  "relations": [
    {
      "sourceName": "源知识点名称",
      "targetName": "目标知识点名称",
      "relationType": "PREREQUISITE_OF/RELATED_TO/PART_OF",
      "weight": 0.8,
      "description": "关系说明（可选）"
    }
  ]
}
```

## 注意事项

- 节点名称应该简洁明确，便于识别
- 重要程度范围：1-5（5为最重要）
- 关系权重范围：0.0-1.0
- 如果文本中没有明确的关系，可以不提取关系
- 每个节点名称在结果中应该唯一
- 确保关系中引用的节点名称与nodes中的name完全一致
